## 💡 为什么写这本书？

面对大模型（LLM）的爆发，初学者与工程师常常陷入两种极端：
1. **玄学拟人派**：把大模型当成有自我意识的生物形态，把 Prompt 包装成神秘咒语，迷信各类营销概念；
2. **论文公式派**：直接被晦涩的学术符号、密集的张量微积分算子和未加解释的术语黑话劝退。

《看懂人工智能》致力于打破这一鸿沟——**「硬核但不晦涩、严谨但极其好懂」**。

本书将大模型彻底还原为**浮点数矩阵、统计概率拟合、GPU 显存/带宽吞吐与自回归因果接龙**的工程物理系统。全书贯彻 **分层认知漏斗（Layered Cognition Funnel）**：

```
┌─────────────────────────────────────────────────────────────┐
│  第 1 层：具象生活隐喻 / 场景切入（5秒建立直觉，0门槛读懂）    │
├─────────────────────────────────────────────────────────────┤
│  第 2 层：物理因果与工程运转机制（大白话拆解，不堆砌生僻数学符号） │
├─────────────────────────────────────────────────────────────┤
│  第 3 层：极简透明代码 / 实验印证（15~30行极简逻辑，带清晰输入输出）│
├─────────────────────────────────────────────────────────────┤
│  第 4 层：工业账本与现实权衡（显存、算力、成本与延迟的真实取舍） │
├─────────────────────────────────────────────────────────────┤
│  第 5 层：击碎误区与清晰认知（读到这里该能分清 + 承上启下）     │
└─────────────────────────────────────────────────────────────┘
```

## ✨ 项目特色

- 🎯 **纯粹因果链**：6 季 · 39 篇体系化概念长文，上篇的物理瓶颈自然引出下篇的架构突破。
- 🎨 **Kami 美学设计**：全书内嵌霞鹜文楷（LXGW WenKai Screen）字体与高信息密度卡片排版。
- 🎬 **3Blue1Brown 矢量动画**：核心动态物理机制（如自回归显存带宽墙）采用 **Manim CE** 引擎生成 60fps 高清矢量动画。
- 📊 **百张专业 SVG 架构图**：宏观流水线、微观机制到工业权衡对比，文字安全边界严格计算，杜绝视觉贴边。
- 🐍 **极简算法心智代码**：每篇配备 15~30 行即开即用的 Python/PyTorch 核心算法卡片。
- 📚 **严谨事实证据链**：每篇文章文末均附带 arXiv 原著论文与官方技术白皮书有效超链接。

## 💻 本地运行与构建

### 环境要求
- **Node.js**：`>= 20.0.0`
- **包管理器**：`npm` / `pnpm`

### 启动步骤

```bash
# 1. 克隆代码仓库
git clone https://github.com/robeshell/ai-learning-book.git
cd ai-learning-book

# 2. 安装依赖
npm install

# 3. 运行规范自检（校验 39 篇元数据、图片存在性与 7 步骨架）
npm run verify

# 4. 启动本地开发热更新服务器
npm run dev
```

本地服务默认运行在：`http://localhost:5173/`。

### 静态构建与预览

```bash
# 构建生产环境静态资源
npm run build

# 本地预览构建产物
npm run preview
```

## 📐 写作规范与自检体系

本项目拥有严格的质量控制体系，详细规则参见 [`SPEC.md`](SPEC.md)：

- **自动化自检工具**：`npm run verify` 会对全书 39 篇长文的 Frontmatter、H1 标题对齐、SVG 配图有效性、`<figcaption>` 精炼度、公式配对及代码完整性进行全自动 CI 扫描。
- **图表文字精炼准则**：`<figcaption>` 严格限制为 10~25 字以内的短语标题，杜绝与正文内容重复。
- **字体与样式**：完全内嵌霞鹜文楷与思源黑体，支持全离线零网络字体加载。
