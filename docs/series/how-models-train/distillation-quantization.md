# 模型蒸馏与量化压缩

大模型当老师、权重降精度，以及 LoRA 一类低成本参数适配。

## 将要讲清

- 蒸馏是把大模型的轨迹教给小模型
- 量化用更少比特存权重，换显存和速度
- LoRA 改的是少量附加参数，不是重训全网
- 瘦身会损失能力，边界要讲清楚
