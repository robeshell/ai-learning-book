# 什么是 Agent Harness

模型只是发动机，宿主操作系统才管理状态、权限和崩溃恢复。

## 将要讲清

- Harness 管生命周期，模型不管
- 权限截获、超时、断点续传都在宿主
- 上下文爆窗时由宿主裁剪，不是模型自觉
- 没有底盘就只是会说话的函数
