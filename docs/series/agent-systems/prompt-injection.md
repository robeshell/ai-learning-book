# 什么是提示词注入

直接和间接注入如何把工具权利用来执行攻击者的指令。

## 将要讲清

- 注入是把攻击指令混进模型正在读的文本
- 间接注入可以藏在网页、邮件、文档里
- 模型分不清“数据”和“指令”时就会被劫持
- 防御在隔离、权限和人审，不在更长的系统提示
