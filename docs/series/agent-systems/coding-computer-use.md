# Coding 与 Computer Use

改代码的 Agent 和看屏幕点鼠标的 Agent，能力边界差在哪。

## 将要讲清

- Coding Agent 依赖仓库索引、测试和补丁循环
- Computer Use 把屏幕当观察，把键鼠当动作
- 两者都把不可逆操作交给宿主审批
- 能操作电脑不等于理解你的意图
