# 什么是上下文窗口

单次推理能看见多远，以及窗口为什么不是长期记忆。

## 将要讲清

- 窗口是单次推理注意力能覆盖的 Token 上限
- System Prompt 占用窗口底仓
- 超限后的 FIFO 截断与压缩
- 会话重置后工作台即销毁，不等于长期记忆
