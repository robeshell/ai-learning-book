# 提示词在做什么

提示词是进入窗口的 Token 序列，不是神秘咒语。

## 将要讲清

- 提示词本质是输入 Token 序列
- 通过注意力收拢下一步的概率轨道
- System 与 User 是分层约束，不是两种魔法
- 提示词不能突破模型的知识和逻辑上限
