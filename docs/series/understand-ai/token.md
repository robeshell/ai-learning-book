# 什么是 Token

文本如何被切成数字编号，以及计费和容量为什么都按 Token 算。

## 将要讲清

- Token 是模型接收和吐出文本的基本单位
- 中英文切分粒度不同，字数不等于 Token 数
- 词表因模型而异，同一段话在不同模型上计数不同
- 计费和上下文上限都以 Token 为度量衡
