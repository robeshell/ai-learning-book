# 严格结构化输出

用 JSON Schema 约束输出，让程序拿到合法数据而不是聊天废话。

## 将要讲清

- 聊天文本对程序不可靠
- JSON Schema / Strict Mode 把语法变成硬约束
- 约束的是形状，不是内容真伪
- 它常和工具调用一起出现
