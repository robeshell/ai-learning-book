# 工具调用与动作执行

模型不亲手调接口，而是生成参数包，由系统执行后再回填。

## 将要讲清

- Tool Calling 是生成结构化请求，不是模型直接联网
- 执行权在宿主系统，不在权重里
- 结果回填窗口后，模型再继续写
- 这是从“只说话”走到“能办事”的分界
