# Skill 专业技能包

把提示词、脚本和规范打成可复用的专业工作法，而不是一段咒语。

## 将要讲清

- Skill 是打包的作业规程，不是一句 prompt
- 它可以包含说明、脚本和资源
- 和 MCP 工具的分工：规程 vs 接口
- 技能包仍然受窗口、权限和幻觉约束
