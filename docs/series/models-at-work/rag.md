# 什么是 RAG

切块、召回、塞进窗口：不重训也能回答私有知识。

## 将要讲清

- RAG 把检索到的片段当作这一次的依据
- 切块粒度会直接决定召回质量
- 它补的是窗口里的事实，不是永久记忆
- 检索错了，生成会一本正经地跟着错
