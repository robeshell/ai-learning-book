基础知识（`docs/series/prerequisites/`）篇章必须纯粹聚焦于基础数学、物理与计算机工程概念，严禁提前引入下游大模型特有术语（如 Transformer QKV、LoRA、KV Cache Radix 树、大模型记忆库等）。

**Why:**
基础知识的目标是为零门槛或跨领域读者打好通用的数学与硬件底座。提前穿插大模型高阶机制会导致认知过载、概念抢跑，破坏渐进式学习路径。

**How to apply:**
1. 聚焦经典通用原理：GPU 并行架构、向量几何与点积、矩阵空间变换与投影、人工神经元与激活非线性拟合、损失函数与梯度下降、无状态请求与通用缓存。
2. 示例与图表使用通用的直观场景（如二维坐标形变、颜色/水果分类、异或问题、下山寻路、通用 API 请求），把基础概念本身讲透。
3. 专栏与文章简介、配图文案同步剔除抢跑的大模型术语。
